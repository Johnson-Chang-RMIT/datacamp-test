# ProMatch UI

This repository contains a minimal demo UI for a professional matching platform.
The interface is implemented with plain HTML, CSS, and React via CDN.

## Running

Open `index.html` in a browser. The UI provides:

- **Profile** form where users can enter basic information
- **Match** view with a Tinder-style card swipe interface
- **Chat** view with a simple message window

This is only a prototype for demonstration purposes.
